# 更新记录

本文件记录《终端与 AI 编程手册》从 V2.0 技术建设、V3.0 全书叙事重构，到 V3.1 Grok Build 专项补充的主要变化。详细文件历史以 Git 为准；当前审查结论见[内容审查记录](内容审查记录.md)，V3.1 详细反查见[V3.1 Grok Build 专项审查](V3.1-Grok-Build专项审查.md)。

## 2026-07-27 至 2026-07-29：建立 V2.0 技术基础

V2.0 将最初的终端教程扩展为覆盖 Git、SSH、Homebrew、Python、Docker、Claude Code、Codex CLI、Grok Build、配置凭证、GPU 远程开发和 AI 工作流的完整手册，并建立 README、SUMMARY、ROADMAP、CONTRIBUTING、Quickstart、Part 01–12 和 Appendix 的基本结构。

| 领域 | 主要结果 |
| --- | --- |
| 终端基础 | 建立 Terminal、Shell、zsh、路径、文件操作、搜索、管道、进程、任务控制和快捷键教程 |
| Git 与协作 | 建立工作区—暂存区—提交—远程模型，覆盖分支、恢复、PR、Worktree 和人工复核 |
| SSH 与远程 | 覆盖主机指纹、用户密钥、SSH Config、scp/rsync、端口转发、分层排错和 Tailscale |
| Python 与 Docker | 区分解释器、pip、venv、Conda、uv 和锁文件；覆盖 Desktop、Engine、Compose、Volume 和 GPU 容器 |
| AI CLI | 分别建立 Claude Code、Codex CLI 和 Grok Build 的安装、认证、权限、会话和自动化章节 |
| 配置与凭证 | 新增 Part 10C，区分模型、Provider、Base URL、凭证、Profile、实例和 Gateway |
| GPU 工作流 | 建立 Mac 日常开发、Ubuntu 24.04 游戏本运行 NVIDIA GPU 的局域网、异网、训练和恢复流程 |
| 自动检查 | 新增严格 Markdown、内部链接、目录引用和脚本检查 |

V2.0 同时确立安全基线：不把 hard reset、clean、强制推送、`sudo pip`、公网 TCP 22、Docker Socket、`--privileged`、订阅凭证转 API 或 AI 全自动高权限模式写成新手默认。

## 2026-07-29 至 2026-07-30：V3.0 全书叙事重构

V3.0 针对“一句一段、短引导—代码块—短解释循环、小标题过密、列表替代解释和跨章模板重复”进行全书重构。更新目标不是继续增加功能数量，而是让一章形成从场景、操作、结果判断到恢复方法的连续过程。

V3.0 建立：

- `V3.0-ROADMAP.md` 和升级后的写作规范；
- 叙事结构、公式化文风、敏感信息和外部链接审计脚本；
- 样章与四个正文批次的内容覆盖反查；
- 私有源仓库到公共仓库的隔离导出、Source Release Audit 和 Release 工作流；
- README 直接内容地图、Quickstart 阅读路线和维护附录。

四个正文批次分别覆盖入口与终端基础、开发基础设施、AI 客户端与配置、远程开发与 AI 工作流；最后完成附录、导航、术语、危险命令、版本核对表和发布机制统稿。V3.0 保留独特命令、故障场景、安全边界和恢复方法，同时显著减少微型段落、空引导、薄小节和重复列表。

V3.0 已正式同步至公共仓库 `anyue-git/Terminal-AI-Coding-Handbook` 的 `main`，公共标签为 `v3.0`。详细变化见[V3.0 发布说明](../RELEASE_NOTES_V3.0.md)。

## 2026-07-30：调整自动检查工作流

自动检查由“生成报告并由 Bot 写回仓库”调整为只读检查和 Artifact 上传：

- Markdown Check 使用 `contents: read`，不再自动提交报告；
- Source Release Audit 构建隔离公开快照，验证真实导出预演、敏感信息和外部链接；
- 静态报告不再作为公共仓库正文入口；
- 自动检查只能证明脚本覆盖的规则通过，不能代替实机测试和人工发布批准。

## 2026-07-31：启动 V3.1 Grok Build 专项补充

用户在实际使用 Grok CLI 时发现斜杠菜单远比原章节丰富，其中还出现跨客户端会话恢复、Memory、Workflow 和多 Agent 等入口。审查确认 Part 10B 原有三章只覆盖安装、权限、Headless、Worktree 和扩展系统概览，无法完整解释当前 Grok Build 的用户功能。

本次更新定位为 **V3.1**，不是 V4.0，也不是全书重构。开发位于私有源仓库 Draft PR #10。

新增六篇正文：

```text
04 TUI、斜杠命令与交互界面
05 会话、Memory 与后台任务
06 Goal、Workflow 与多 Agent 系统
07 扩展系统、MCP、ACP 与跨客户端兼容
08 配置、模型、诊断与功能核对
09 终端子命令与完整功能索引
```

主要补充：

- 解释 Agent Builtin、Pager Builtin 与 Skill Command 的来源差异；
- 覆盖 `/share`、`/transcript`、`/queue`、`/tasks`、会话、上下文、模型、权限、设置和媒体入口；
- 区分 Session、Compact、Transcript、Export、Share、Memory、Dashboard 和 Loop；
- 说明 Background Workflows 默认开启、Goal 的两种驱动、Workflow 的非 exactly-once 恢复边界；
- 记录 Agent Budget 默认 128、显式范围 1–1024，并与 Token Budget、费用和时间分开；
- 系统说明 Skill、Plugin、Marketplace、Hook、MCP、LSP、ACP、Agent 和 Persona；
- 区分 `/import-claude` 设置迁移、`grok import` Claude 会话导入和 staged 的 `resume-*` Scanner 路线；
- 明确 `resume-codex` 不是可以无条件宣传的稳定内置恢复；
- 整理官方 CLI 子命令、Headless、Worktree、权限、Sandbox、工具集合和企业 Setup Flags；
- 增加 V3.1 发布说明和专项审查记录。

本轮依据 2026-07-31 的 xAI 官方在线文档与 `xai-org/grok-build` 上游用户指南。两套资料出现短暂同步差异时，文档会保留差异说明，并要求使用作者真实安装版本的 `/help`、`grok --help` 和 `grok inspect` 复核。
