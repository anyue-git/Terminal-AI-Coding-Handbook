# 术语表

本表给出本书中高频概念的简明定义。第一次遇到陌生词时，可以先看这里，再进入对应章节。

## Terminal

显示文字界面、接收键盘输入并展示程序输出的终端程序或终端模拟器。macOS Terminal、iTerm2 和 VS Code 集成终端都属于这一层。

## Shell

解释命令、变量、通配符、管道和重定向，并启动其他程序的命令解释器，例如 zsh、bash 和 fish。

## zsh

Z Shell。macOS 当前默认 Shell，提供命令历史、补全、配置文件和 ZLE 命令行编辑能力。

## ZLE

Zsh Line Editor。zsh 在普通提示符中处理光标移动、删除、历史搜索和按键绑定的组件。

## CLI

Command-Line Interface，命令行界面。通过命令和参数使用程序，例如 `git`、`ssh` 和 `docker`。

## TUI

Text User Interface，文本用户界面。运行在终端中，但可能包含输入框、菜单、窗口和快捷键，例如部分 AI CLI 交互界面。

## Agent

能根据目标读取上下文、调用工具、修改文件并迭代执行任务的软件系统。Agent 能做什么取决于当前权限、工具和运行环境。

## AI CLI

运行在终端中的 AI 编程客户端，例如 Claude Code、Codex CLI 和 Grok CLI。客户端不一定等于模型供应商。

## 模型后端

真正接收请求并生成结果的模型服务。客户端可能连接官方模型 API、云平台、企业网关或兼容供应商。

## 模型供应商

提供模型推理、计费、日志和数据处理服务的组织。直连模型厂商和通过中转平台调用，属于不同信任链。

## LLM Gateway

位于客户端与一个或多个模型供应商之间的网关。它可能负责统一认证、路由、审计、限流和模型映射。

## Anthropic 兼容接口

在请求与响应格式上兼容 Anthropic Messages API 的服务。协议兼容不等于 Claude Code 的所有功能、工具调用和模型行为完全一致。

## MCP

Model Context Protocol。让 AI 客户端连接外部工具和数据源的协议。MCP Server 的权限和返回内容都需要纳入安全边界。

## Hook

在特定事件前后自动执行的命令或脚本，例如工具调用前检查、任务结束后运行测试。Hook 会扩大自动执行范围。

## Skill

为 Agent 提供任务说明、脚本和参考资料的可复用能力包。Skill 内容也可能包含需要审查的命令和外部依赖。

## Prompt Injection

通过文档、网页、工具输出或其他输入诱导模型偏离原任务、泄露数据或执行越权操作的攻击方式。

## 当前工作目录

Shell 当前所在的目录。相对路径、许多文件命令和 AI CLI 的默认工作范围都以它为起点。

## 项目根目录

项目的主要目录，通常包含 `.git`、`README.md`、`pyproject.toml`、`package.json` 等标志文件。

## 绝对路径

从文件系统根目录 `/` 开始的完整路径，例如 `/Users/name/Projects/demo`。

## 相对路径

相对于当前工作目录的路径，例如 `src/app.py`。

## 主目录

当前用户的个人目录，用 `~` 表示。macOS 常见为 `/Users/NAME`，Ubuntu 常见为 `/home/NAME`。

## PATH

Shell 查找可执行命令时依次搜索的目录列表。多个同名命令存在时，PATH 顺序会影响最终运行哪一个。

## 环境变量

进程可以读取的键值配置，例如 `PATH`、`HOME`、模型端点和 API Key。子进程通常继承父进程的环境变量。

## 标准输入

stdin，程序读取输入的默认通道。

## 标准输出

stdout，程序输出正常信息的默认通道。

## 标准错误

stderr，程序输出错误和诊断信息的默认通道。管道默认只传递 stdout。

## 管道

使用 `|` 把左侧命令的标准输出交给右侧命令作为输入。

## 重定向

把输入或输出改到文件或其他通道，例如 `>` 覆盖写入、`>>` 追加和 `2>` 保存错误。

## 退出状态

命令结束时返回的数字。通常 0 表示成功，非 0 表示失败或其他状态；`&&` 和 `||` 据此决定是否继续。

## 进程

正在运行的程序实例，通常拥有 PID、用户、环境变量和打开的文件。

## 前台进程

当前占用终端交互的进程。键盘输入会先交给它，而不是 Shell。

## 后台进程

不占用当前 Shell 输入位置的进程。后台运行不等于脱离终端，也不保证 SSH 断开后继续。

## PID

Process ID，进程编号。结束进程前应核对 PID、用户和启动命令。

## tmux

终端复用器。它允许会话和进程在 SSH 断开后继续，并可稍后重新接入；不能抵御关机、程序崩溃或磁盘故障。

## Git 仓库

由 Git 管理提交历史、分支和工作区状态的项目目录，内部数据通常保存在 `.git`。

## 工作区

Git 仓库中当前可见和可编辑的文件状态。

## 暂存区

Index 或 Staging Area。下一次提交准备包含的内容，可使用 `git diff --cached` 检查。

## Commit

Git 提交。记录一个项目快照、父提交、作者和说明。

## HEAD

Git 当前检出的分支或提交位置。

## Branch

Git 分支。本质上是指向提交的可移动引用，不是完整项目副本。

## Remote

远程 Git 仓库的连接定义，例如常见名称 `origin`。

## Pull Request

围绕一个分支相对于目标分支的差异进行讨论、测试、审查和合并的协作机制。

## Worktree

同一 Git 仓库的额外工作目录，适合并行处理不同分支。它隔离工作区，不隔离系统权限、网络和凭据。

## Reflog

Git 本地引用移动记录，可帮助找回误 reset 或误移动前的提交。它不是永久备份。

## SSH

Secure Shell。用于安全远程登录、执行命令、传输文件和建立端口转发。

## SSH Client

发起 SSH 连接的客户端程序，例如 Mac 上的 `ssh` 命令。

## SSH Server

接受 SSH 连接的服务端程序，例如 Ubuntu 上的 OpenSSH Server `sshd`。

## SSH 主机密钥

证明远程服务器身份的密钥。首次连接应核对指纹，变化时应先调查原因。

## SSH 用户密钥

用于客户端身份认证的密钥对。私钥保存在客户端，公钥写入服务器的 `authorized_keys`。

## 端口转发

通过 SSH 加密连接转发网络端口。`ssh -L` 常用于在本机安全访问远程 Jupyter 或开发服务。

## Tailscale

基于 WireGuard 的安全组网工具，用于让不同网络中的设备通过私有地址或名称互相访问。

## DERP

Tailscale 的加密中继路径。无法建立直接连接时可经 DERP 转发，通常延迟更高但通信仍加密。

## Homebrew

macOS 常用软件包管理器，用于安装、升级和卸载命令行工具、图形应用及部分后台服务。

## Formula

Homebrew 中通常表示命令行工具、库或服务的软件包定义。

## Cask

Homebrew 中通常表示 macOS 图形应用或大型软件包的安装定义。

## 虚拟环境

为项目隔离 Python 解释器入口和第三方包的目录或环境，例如 venv、Conda 环境或 uv 管理的 `.venv`。它不是虚拟机。

## Lockfile

锁文件。记录依赖解析结果，帮助在不同时间重建接近一致的依赖版本，例如 `uv.lock`。

## Docker Image

Docker 镜像。用于创建容器的只读分层模板。

## Docker Container

镜像的运行实例。容器共享宿主机内核，不是完整虚拟机。

## Volume

由 Docker 管理、独立于单个容器生命周期的数据存储。

## Bind Mount

把宿主机路径直接挂入容器。容器对挂载路径的修改会影响宿主机文件。

## Docker Socket

Docker daemon 的控制接口，常见路径为 `/var/run/docker.sock`。访问它通常意味着很高的宿主机控制能力。

## Sandbox

用于限制程序可访问文件、网络、进程或系统能力的隔离机制。Sandbox 的强度取决于具体实现和配置。

## Approval

Agent 在执行命令、修改文件或访问外部资源前请求人工确认的机制。审批和 Sandbox 是不同维度。

## API Key

调用网络服务时使用的秘密凭据，应像密码一样保护，不应进入 Git、截图、日志或聊天。

## Session Token

表示已登录会话的敏感令牌。泄露后可能允许他人冒用会话，不应作为非官方 API 接入方式。

## Refresh Token

用于申请新访问令牌的长期敏感凭据，通常比短期 Access Token 更需要保护。

## Checkpoint

训练过程中保存的可恢复状态，通常包含模型、优化器、调度器、步数和随机状态。它与普通模型权重文件不完全相同。

## CUDA Driver

NVIDIA 驱动层，负责操作系统与 GPU 硬件通信。`nvidia-smi` 主要反映这一层。

## CUDA Toolkit

包含 `nvcc`、头文件和开发库的系统开发工具包。运行预编译 PyTorch wheel 不一定需要本机安装完整 Toolkit。

## CUDA Runtime

应用运行时使用的 CUDA 用户态库。PyTorch wheel 或容器镜像可能自带对应 Runtime。

## MPS

Metal Performance Shaders。PyTorch 在 Apple Silicon Mac 上使用 GPU 的后端之一，不能替代 Ubuntu NVIDIA CUDA 验证。
