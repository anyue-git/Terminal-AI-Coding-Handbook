# 快捷键速查表

> 适用范围：macOS 默认 zsh 的常见 Emacs 键位。
>
> 插件、Vi 模式、tmux、AI CLI 和其他 TUI 可能重新定义按键。普通 zsh 中的实际绑定以 `bindkey` 输出为准。

## 命令行编辑

| 快捷键 | 常见作用 | 适合解决的问题 |
|---|---|---|
| `Ctrl + A` | 移到行首 | 修改命令开头 |
| `Ctrl + E` | 移到行尾 | 回到参数末尾继续输入 |
| `Ctrl + W` | 删除光标左侧一个单词 | 删除参数、文件名或路径片段 |
| `Ctrl + U` | 默认 zsh 中通常清除当前输入 | 整行重写 |
| `Ctrl + K` | 删除光标右侧到行尾 | 保留前半段，重写后半段 |
| `Ctrl + Y` | 粘回最近 Kill 的内容 | 恢复刚被 `Ctrl + U/K/W` 删除的内容 |
| `Option + ←` | 向左移动一个单词 | 编辑长命令 |
| `Option + →` | 向右移动一个单词 | 编辑长命令 |
| `Option + Delete` | 删除左侧一个单词 | 终端已把 Option 配置为 Meta 时使用 |

检查真实绑定：

```bash
bindkey '^A'
bindkey '^E'
bindkey '^U'
bindkey '^K'
bindkey '^W'
bindkey '^Y'
```

Option 组合键无效或出现奇怪字符时，检查 Terminal、iTerm2、Warp 等终端对 Option/Meta 的设置。

## 运行控制

| 快捷键 | 常见作用 | 注意 |
|---|---|---|
| `Ctrl + C` | 取消当前输入，或向前台程序请求中断 | AI CLI 中可能只停止当前生成 |
| `Ctrl + Z` | 暂停前台程序 | 不是结束；用 `jobs`、`fg`、`bg` 管理 |
| `Ctrl + D` | 删除字符、列出补全或发送 EOF | 空行时可能退出 Shell |
| `Ctrl + L` | 重新整理当前显示区域 | 不删除历史、文件或进程 |

任务控制：

```bash
jobs
fg
bg
```

## 历史命令

| 快捷键 | 作用 |
|---|---|
| `↑` | 上一条历史命令 |
| `↓` | 下一条历史命令 |
| `Ctrl + R` | 反向搜索历史 |
| 再按 `Ctrl + R` | 查找更早的匹配 |
| `Ctrl + C` | 取消历史搜索 |

历史命令可能包含旧路径、旧服务器或危险参数。接受搜索结果后先检查，再执行。

## macOS 复制粘贴

| 快捷键 | 作用 |
|---|---|
| `Command + C` | 复制选中文本 |
| `Command + V` | 粘贴 |
| `Ctrl + C` | 取消或中断，不是复制 |

某些终端在没有选中文本时会把 `Command + C` 交给应用处理，但普通命令中断仍使用 `Ctrl + C`。

## 常见交互程序

| 程序或状态 | 正常退出方式 |
|---|---|
| 普通 Shell | `exit` |
| `less` | `q` |
| `top` | `q` |
| `tail -f` | `Ctrl + C` |
| SSH 正常会话 | `exit` |
| SSH 卡死 | 新行开头输入 `~.` |
| tmux 脱离 | `Ctrl + b`，再按小写 `d` |

进入 Claude Code、Codex CLI 或 Grok CLI 后，先使用工具自己的帮助界面确认快捷键。不要为了一个 TUI 中的按键差异，直接重写整个 `.zshrc`。
