# V3.0 文风二次审查

> 最近更新：2026-07-30  
> 正文数据来源：Source Release Audit #187，正文头提交 `5ebae1a1f468347711df851467d497ccbc831ebf`

第一轮 V3 重构主要处理一句一段、短引导、薄小节、列表替代解释和重复代码卡片。指标改善后，仍可能出现另一种“GPT 病”：段落虽然变长，章节却继续套用同一流程；不同产品只替换名称，安全提醒和收尾句几乎相同；读者正文混入 PR、Actions 和发布闸门；或者为了消除短段，把不同问题压成难以扫描的一整块文字。

第二轮不以继续压缩篇幅为目标，而是重新判断每章负责什么。产品专章只保留产品特有能力，通用工作流集中到 Part 12，Git、SSH、Python、Docker 和远程开发的共同原理回到各自主讲章节。命令、错误场景、安全边界和恢复方法必须保留；结构指标不能单独证明内容完整，代码块也必须检查读者实际复制到终端时看到的字符。

## 1. 判断标准

人工通读重点检查：

- 多章是否连续使用同一套“调查—计划—实施—验证—警告”；
- Claude Code、Codex CLI 和 Grok Build 是否只更换产品名，却重复同一套 Prompt、Git 和安全说明；
- 小节是否反复以“不要”“不能”“不等于”收尾，警告密度压过原理和操作；
- 是否连续使用“先—再—最后”“不是……而是……”“真正……”等固定转折；
- 读者入口是否详细解释当前分支、Draft PR、Actions 或发布流水线；
- 本可合并的命令卡片是否仍保持“一句引导—代码块—一句提醒”；
- 为追求长段落是否牺牲步骤扫描、参数对照或故障定位；
- 合并重复内容后，是否误删唯一命令、代表性报错、恢复路径或平台差异；
- 代码示例经过 Markdown、API 或字符串转义后，是否仍保持原始参数、反斜杠、引号和换行语义。

模板库、速查表、命令清单和故障矩阵本来就需要结构化表达，不能因为排版整齐就改成散文。警告词、段落长度和标题数量只用于定位候选，不能自动决定删除。

## 2. 候选审计与正确统计口径

`scripts/audit_formulaic_style.py` 已接入 Markdown Check 与 Source Release Audit。脚本忽略围栏代码、表格和列表，报告跨文件重复长句、重复段落开头、警告句密度、公式化转折和 300 字以上自然段候选。它不是质量门；SSH 私钥、Docker Volume、危险命令和 checkpoint 等章节可能因为真实安全边界而出现较高警告密度，仍需人工判断。

#187 覆盖 69 个读者正文文件、1734 个自然段和 3576 个句子，没有发现跨文件完全重复长句，也没有 300 字以上普通自然段。当前主要风险已经从“整句复制和文字墙”转为章节职责重叠、命令密集章节的短段节奏、重构后内容覆盖是否完整，以及代码示例转义是否在写入过程中发生变化。

## 3. 入口与基础章节

README 已从面向维护者的分支、Draft PR、Actions 和发布闸门说明改回阅读路线、内容地图、默认环境、安全边界和简短版本状态。

《终端十五分钟上手》保留全部练习步骤，减少连续固定转折；《AI CLI 快速上手》把可复制任务模板交回 Prompt 模板库；完整 Quickstart 仍保留独立项目、Git 基线、Agent 调查、分步修改和提交练习，因为它是一条可脱离真实项目运行的完整学习路径。

`pwd/ls/cd`、文件创建/复制/移动/删除和进程控制已分别改成连续导航、文件生命周期与进程生命周期。文件操作章经 V2 对照后确认仍覆盖覆盖确认、特殊文件名、变量展开、待清理区和 Git 恢复，不因短段排名继续压缩。

本轮发现《Shell 到底是什么》和《查看文本文件与日志》中部分 `printf` 格式字符串的 `\n` 曾在文件写入过程中变成真实换行。它们没有破坏 Markdown 围栏，Shell 甚至可能继续把内容解释为多行字符串，因此原有检查没有报警。示例已改回显式 `\n`，`scripts/test_audit_tools.py` 现在会扫描 Bash、sh、Shell 与 zsh 围栏，阻止 `printf` 的格式参数跨越物理行。

## 4. 开发基础设施与 AI CLI 产品章节

Homebrew 服务章保持“后台服务—真实进程与数据—多版本与路径—可解释排错”四条主线。本轮补回 `brew services info`、`brew services list --debug`、废弃服务登记清理，以及 Apple Silicon 上分别核对 `/opt/homebrew` 与 `/usr/local` 服务视图的方法。新增内容没有恢复旧版十六个标题；当前标题为 5、薄小节为 0。

Homebrew 与 PATH 章此前已经补回 `sudo brew` 的权限污染风险、前缀所有者检查和最小恢复边界。Python 解释器章合并为定位、虚拟环境、受控缺包、故障与权限、跨平台结论；依赖复现章补回 `sys_platform`、extras/dependency groups、包来源与私有索引，以及 uv/pip/Conda 的分层复现诊断。

三篇安装章不再各自创建一套 Python 练习项目。Claude Code、Codex CLI 和 Grok Build 分别聚焦安装来源、真实二进制路径、认证、账户与计费、首次目录状态和自身故障。三篇权限章只保留产品差异，通用 Shell、网络、凭据、Docker、SSH 与不可逆操作由 Part 12 权限总览承担。

Claude Code 会话章在覆盖反查后补回项目级 MCP、凭据不写入 `.mcp.json`、提示注入和模型/MCP 双数据链。大任务章只保留命名 Plan 会话、上下文管理、独立 Review、Claude Worktree、`.worktreeinclude` 和子 Agent。Claude Code 配置/网关章与 V2 对照后确认设置作用域、认证优先级、Token 类型、Helper、Gateway、多开和故障入口仍完整。

Codex Git 案例围绕只读/可写 Sandbox、`AGENTS.md`、分批实施、`resume`、Review、`/fork` 和 Worktree，Git 发布流程交回 Part 04；TOML 章按状态目录、优先级/Profile、Provider/凭证和第二实例组织。Codex 自动化章本轮逐项对照 V2，TUI/`exec`、工作目录、Git 检查、非交互权限、会话恢复、JSONL、Schema、只读审计脚本、修改型任务、退出状态、超时和 CI 凭据均有承接；完整任务合同明确链接到 Prompt 模板库，因此不恢复旧版二十个小节。

Grok 安装、权限和 Headless 三章分别改成四条主线。覆盖反查补回 `--tools`、`--disallowed-tools`、JSONL 前向兼容和模型/推理强度证据。CC Switch、`ccswitch` 与 Cockpit Tools 章分清配置投影、凭证替换与本地路由，并说明 sidecar、Keychain、环境变量覆盖、监听地址、恢复控制面和订阅 OAuth 边界。

## 5. Git、Docker、远程开发与通用工作流

Git 日常流程新增工作区与暂存区 `git diff --check`，并使用 `git status --ignored --short` 验证忽略规则；Pull Request 章补回远程分支清理依赖仓库设置，以及 Worktree 不能消除接口和数据格式的语义冲突。

Docker 核心、Compose、GPU 容器和 Desktop/Ubuntu Engine 都完成 V2 反查。除了构建上下文、变量插值、镜像 digest、UID/GID 等内容，Mac 现在还可通过命名 SSH Context 显式操作 Ubuntu Engine；远程 Bind Mount 明确按 Ubuntu 路径解释，并推荐逐条使用 `--context`，避免全局切换后误操作错误 daemon。

日志章与管道章本轮也完成 V2 对照。`cat`/`less`/`tail`、`tee`、`pipefail`、stdout/stderr、退出状态、引号、命令替换和数据外发边界均有承接；缩减主要来自重复输出和连续命令卡片，因此只修复示例转义，不为了增加字符恢复旧结构。

《通用 AI 编程闭环》以一个解析器案例贯穿需求、基线、调查、分批实施、测试、diff、复核和提交；表单留在 Prompt 模板库。权限总览只讲权限层次，复杂任务章只讲决策边界、证据账本、批次预算、独立复核和暂停条件，并补回每批测试的命令、环境、退出状态、通过/失败/跳过、警告和覆盖范围。

Part 11 中，局域网部署不再复制完整 SSH 密钥教程；项目同步不再复制 Git 提交与 rsync 基础；tmux 聚焦会话、日志、监控、停止和断线演练；NVIDIA 保留驱动、Toolkit、Runtime、真实计算与分层排错；跨平台环境只讲声明共享和两端重建；实验日志与 Checkpoint 保留代码快照、日志、退出状态、原子替换、恢复演练、哈希、磁盘和回传。

## 6. 经复核后保留原结构的章节

- Prompt 模板库与基础设施 Prompt：固定字段和列表就是可复制产物；
- 完整 Quickstart：独立项目与 Git 基线让练习可脱离真实仓库执行；
- Git 分支与安全恢复：顺序词对应工作区、暂存区、合并、共享提交和 reflog 的真实层次；
- SSH 首次连接、密钥、传输与故障排查：短段分别对应服务、TCP、主机身份、用户认证、方向和备用入口；
- 快捷键速查与核心快捷键：分区便于按键查找；
- 文件操作、zsh、管道、日志和危险命令清单：限制说明紧贴实际 Shell、数据流与文件风险。

“保留原结构”不表示永远不再审查，而是当前没有足够证据证明进一步合并会改善阅读而不损害技术边界。
