## 3. Part 01：基础概念职责重新划分

《为什么程序员离不开终端》集中解释可复现操作、工具组合、远程机器、AI 加速与自动化风险，不再重复后续章节的完整命令教程。Git 状态、管道、SSH 和错误信息示例仍然保留，用来说明终端为何可观察、可记录和可复现。

《Terminal 到底是什么》只负责窗口、当前程序、提示符、远程会话、关闭窗口与清屏的区别。Terminal、Shell、AI CLI、分页器、SSH 和 VS Code 集成终端之间的输入层级得到连续解释，原有 `TERM_PROGRAM`、`$SHELL`、`ps`、`hostname`、`whoami`、`pwd`、tmux 和清屏实验均保留。

《Shell 到底是什么》集中解释命令解析、内建与外部程序、PATH、通配符、引号、管道、退出状态、环境变量以及 AI CLI 作为子程序的关系。重复的“一条命令—一个输出—一句解释”被合并成解析过程，但 `type`、`command -v`、PATH 展示、变量保护和故障检查命令没有删除。

《zsh 到底是什么》集中解释 ZLE、启动文件、补全、历史、alias、函数、PATH、环境变量和启动错误恢复。`.zshrc`、`.zprofile`、`zsh -n`、`source`、`zsh -f`、`bindkey` 以及凭证历史风险均保留。快捷键的具体教学移交 Part 03，zsh 章只解释配置来源和排查边界。

《文件系统、目录与路径》使用一棵练习文件树统一说明绝对路径、相对路径、根目录、主目录、项目根目录、隐藏文件、空格、大小写、符号链接和路径变量。原有各概念没有删除，但十二个细小章节重组为六个问题，最终形成“路径决定操作边界”的一条主线。

## 4. Part 02：命令改为连续任务

`pwd`、`ls` 与 `cd` 章继续使用 `navigation-demo`，保留详细列表、隐藏文件、`ls -ld`、目录切换、Tab 补全、空格、`no such file or directory`、`not a directory`、项目进入流程和远程导航。重写后按“建立现场、移动、特殊路径、错误恢复、项目启动、完整练习”组织。

文件操作章继续使用 `file-operations`，保留 `mkdir`、`touch`、`printf`、`cp`、`mv`、`rm -i`、`rmdir`、通配符预览、待清理目录、连字符文件名、变量路径和 Git 恢复边界。本章没有提供递归强制删除模板，也没有把 Git 描述成能够恢复未跟踪文件和项目外数据。

文本与日志章保留文件类型与规模判断、`cat`、`less`、`head`、`tail -f`、`wc`、`tee`、`pipefail`、JSON/CSV/二进制查看、敏感信息检查和实际日志排查顺序。工具不再各自形成孤立章节，而是按照“打开前判断—选择阅读方式—持续追踪—格式差异—隐私—定位错误”组织。

搜索章保留 BSD/GNU `find` 差异、候选清单、`grep` 上下文、`rg` 与 `.gitignore`、正则与固定字符串、NUL 分隔特殊文件名、从日志定位源码、Secret 基础检查和只读 Agent Prompt。搜索结果仍明确只是线索，不能直接连接删除或据此宣称根因。

管道章保留 stdin/stdout/stderr、管道、覆盖与追加、分别重定向错误、`tee`、`pipefail`、退出状态、`&&`、`||`、`;`、命令替换、引号、逐步构建处理链和敏感数据流向。符号被放回同一条数据流中解释，不再每个操作符单独重复开场。

进程章保留前台、`Ctrl + C`、`Ctrl + Z`、`jobs`、`fg`、`bg`、后台 `&`、PID、`ps`、`pgrep`、TERM、`pkill` 风险、`nohup`、tmux、Agent 长任务约束和完整练习。任务编号、PID、系统进程和 tmux 会话仍严格区分，后台运行也没有被写成可靠断线续跑。

## 5. Part 03：快捷键按功能分组

命令行编辑章继续使用“不按回车的长命令”作为安全练习，保留 `bindkey` 实际检查、`Ctrl + A/E/W/U/K/Y/R/C/Z/L/D`、Option 或 Esc 单词移动、历史复核、前台中断、任务暂停、清屏、EOF、AI CLI/TUI/tmux 按键层级和故障排查。

原有十四个快捷键小节重组为七个功能问题：安全练习、光标移动、删除与恢复、历史搜索、控制类按键、程序层级和最小记忆集。按键差异仍以当前 Shell 和程序的真实绑定为准，没有把某一平台的行为写成永久规则。

## 6. 删除、合并和事实修正原则

本批次删除的主要内容是重复的“运行：”“可能看到：”“查看：”等空引导、同一安全原则在相邻位置的重复表述，以及仅用于承载下一条命令的微型标题。独特命令、代表性输出、错误恢复和凭证边界没有因为压缩版面而无说明消失。

跨章重复通过职责划分处理：Terminal 章讲输入交给谁，Shell 章讲命令如何解析，zsh 章讲 macOS Shell 配置，快捷键章讲实际按键；文件系统章讲路径概念，导航章讲操作练习；日志章讲阅读，搜索章讲定位，管道章讲数据流，进程章讲运行状态。

除 README 项目状态同步外，本批次没有宣称对所有命令重新完成真实设备验证，也没有把版本化外部事实更新混入文风修改。后续若发现命令或工具事实需要修正，应在覆盖记录中单独列出依据。
