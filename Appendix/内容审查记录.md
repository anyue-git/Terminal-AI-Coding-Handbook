## 5. V3.1 的关键安全判断

```text
会话恢复 ≠ 项目恢复
Fork ≠ Git 分支
Rewind ≠ 外部副作用回滚
Compact ≠ 无损历史
Memory ≠ 可信事实库
Share ≠ 本地导出
Persona ≠ 权限隔离
Worktree ≠ 网络、数据库、Docker 或 GPU 隔离
Always-approve ≠ Sandbox
关闭 Web Search ≠ 禁止全部联网
```

Goal、Workflow、Loop 和多 Agent 会增加运行时间、并发、外部调用和恢复复杂度。生产发布、数据库迁移、付款、权限变更和删除默认只做只读调查与方案生成；写入需要人工门槛、幂等设计和产品自身回滚机制。


- 所有 Grok 命令已在作者当前版本出现；
- 所有账号和组织都拥有相同功能；
- Memory Backend、Goal、Workflow 和 ACP 已在真实环境运行；
- 第三方 Plugin、MCP 和 Skill 安全；
- 外部服务、费用和政策不会变化；
- 文档中的每个命令都已在 Mac、Ubuntu、SSH 和远程终端抽样。
