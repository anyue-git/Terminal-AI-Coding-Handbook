# 05 文件系统、目录与路径

终端中的大多数操作都依赖当前目录。图形界面通过窗口告诉你打开了哪个文件夹；Shell 则维护一个“当前工作目录”。

查看：

```bash
pwd
```

许多命令默认作用于这里：

```bash
ls
python app.py
git status
claude
codex
```

---

## 1. 绝对路径和相对路径

绝对路径从文件系统根目录 `/` 开始：

```text
/Users/NAME/Projects/demo
```

无论当前在哪里，它都指向同一位置。

相对路径依赖当前目录：

```text
src/main.py
```

如果当前目录是：

```text
/Users/NAME/Projects/demo
```

完整位置就是：

```text
/Users/NAME/Projects/demo/src/main.py
```

相对路径更短，但使用前必须知道当前上下文。

---

## 2. 常用路径符号

```text
/    文件系统根目录
~    当前用户主目录
.    当前目录
..   上一级目录
-    cd 中表示上一次所在目录
```

示例：

```bash
cd ~
cd ..
cd -
open .
```

`/` 不是个人主目录。不要在不理解系统目录结构时直接对根目录进行递归修改。

---

## 3. 项目应该放在哪里

个人项目适合放在主目录下，例如：

```text
~/Projects
~/Code
~/Developer
```

不要把普通项目直接放进：

```text
/System
/usr
/bin
/etc
```

这些属于系统或全局软件环境。

一个项目根目录常见标志：

```text
.git/
README.md
pyproject.toml
package.json
Dockerfile
```

启动 AI CLI 前应进入项目根目录：

```bash
cd ~/Projects/my-project
pwd
ls -la
git status
claude
```

从家目录或多个仓库的父目录启动 Agent，会扩大它能看到的内容，也容易在错误位置创建文件。

---

## 4. 隐藏文件并不等于不重要

名称以 `.` 开头的文件通常被隐藏：

```text
.git
.env
.zshrc
.gitignore
```

显示它们：

```bash
ls -la
```

其中可能包含：

- Git 历史；
- API Key；
- Shell 配置；
- 工具权限规则。

不要把“看不到”理解成“不存在”或“不敏感”。

---

## 5. 空格和大小写

路径有空格时：

```bash
cd "My Project"
```

或使用 Tab 补全。

macOS 默认文件系统通常保留大小写但不严格区分，Linux 通常严格区分：

```text
File.py
file.py
```

跨 Mac 和 Ubuntu 的项目应保持文件名大小写一致，避免只在 Linux 上暴露问题。

---

## 6. 变量中的路径要加引号

```bash
printf '%s\n' "$TARGET_DIR"
```

使用：

```bash
cp "$SOURCE_FILE" "$TARGET_DIR/"
```

不要写成：

```bash
cp $SOURCE_FILE $TARGET_DIR/
```

未加引号时，空格和通配符可能被 Shell 再次拆分或展开。

---

## 7. 危险操作前检查什么

涉及删除、覆盖、同步和权限修改时，先运行：

```bash
hostname
pwd
ls -la TARGET
```

命令包含变量时：

```bash
printf 'TARGET=%q\n' "$TARGET_DIR"
```

如果变量为空、路径拼错或指向项目外目录，应立即停止。

不要把下面这种命令当成通用模板：

```bash
rm -rf "$TARGET_DIR"
```

只有在目标路径经过独立验证，并且确认可恢复时才考虑递归删除。

---

## 8. Mac 与 Ubuntu 的路径不同

Mac 常见：

```text
/Users/NAME/Projects/demo
```

Ubuntu 常见：

```text
/home/NAME/projects/demo
```

不要把一台机器的绝对路径直接写死到另一台机器。项目配置可使用：

- `$HOME`；
- 环境变量；
- 本地配置文件；
- 相对于项目根目录的路径。

---

## 9. 最短检查习惯

```bash
hostname
pwd
ls -la
git status
```

尤其在这些场景先检查：

- SSH 登录远程机器；
- 删除和移动文件；
- 运行安装命令；
- 启动 AI CLI；
- 同步项目；
- 运行训练；
- 使用 Docker Bind Mount。
