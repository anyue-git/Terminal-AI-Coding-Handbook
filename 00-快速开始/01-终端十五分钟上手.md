# 01 终端十五分钟上手

> 适合第一次打开终端，或者临时忘记常用操作时快速查看。
>
> 目标是在 15 分钟内掌握一条安全、可用的最短路径，而不是一次学完所有终端知识。

---

## 1. 先知道自己在操作什么

```text
Terminal
→ 显示文字、接收键盘输入的窗口

Shell
→ 解释和执行命令，macOS 默认通常是 zsh

CLI
→ 在终端中运行的具体工具，例如 git、python、claude、codex
```

你输入：

```bash
pwd
```

Shell 会解释并执行它。

你输入：

```bash
git status
```

Shell 会启动 Git 这个 CLI 工具。

## 2. 每次操作前先确认机器和目录

先运行：

```bash
hostname
whoami
pwd
```

它们分别表示：

- `hostname`：当前是哪台机器；
- `whoami`：当前是什么用户；
- `pwd`：当前位于哪个目录。

通过 SSH 登录 Ubuntu 后，终端界面可能和 Mac 很像，但命令已经在远程机器执行。

因此在删除、覆盖、安装或启动训练前，至少再确认一次：

```bash
hostname
pwd
```

---

## 3. 查看和进入目录

查看当前目录：

```bash
ls
```

查看隐藏文件与详细信息：

```bash
ls -la
```

进入项目：

```bash
cd ~/Projects/my-project
```

进入上一级：

```bash
cd ..
```

回到家目录：

```bash
cd ~
```

返回刚才的目录：

```bash
cd -
```

目录名含空格时使用引号：

```bash
cd "My Project"
```

进入后立即确认：

```bash
pwd
ls -la
```

## 4. 输错命令时怎么快速修改

普通 macOS zsh 的常见默认按键：

```text
Ctrl + A
→ 移到行首

Ctrl + E
→ 移到行尾

Ctrl + W
→ 删除光标左侧一个单词

Ctrl + U
→ 常见默认行为是删除当前整行

Ctrl + C
→ 放弃当前输入，或中断前台程序

方向键上 / 下
→ 浏览历史命令

Ctrl + R
→ 搜索历史命令
```

快捷键可能被 Vi 模式、插件、tmux 或 AI CLI 的全屏界面改变。

需要验证时：

```bash
bindkey '^U'
bindkey '^W'
```

不要把 `Ctrl + U` 机械记成所有环境中都相同的行为。

## 5. 创建、查看、复制和移动

创建空文件：

```bash
touch notes.md
```

创建目录：

```bash
mkdir practice
```

创建多层目录：

```bash
mkdir -p project/src
```

查看短文件：

```bash
cat notes.md
```

分页查看长文件：

```bash
less README.md
```

在 `less` 中按 `q` 退出。

复制文件：

```bash
cp notes.md notes-backup.md
```

移动或重命名：

```bash
mv notes.md project-notes.md
```

执行覆盖操作前先检查目标：

```bash
ls -ld SOURCE TARGET
```

## 6. 删除前必须停一下

删除普通文件：

```bash
rm FILE_NAME
```

删除前至少确认：

```bash
hostname
pwd
ls -ld FILE_NAME
```

涉及通配符时先预览：

```bash
printf '%s\n' PATTERN
```

不要让 AI 自动批准：

- 项目目录之外的删除；
- 含通配符的大范围删除；
- 带管理员权限的删除；
- 路径变量值不明确的删除；
- 数据集、模型和 checkpoint 删除。

本快速入口不提供递归强制删除示例。需要时先阅读：

- [危险命令清单](../Appendix/危险命令清单.md)
- [创建、复制、移动与删除](../Part-02-终端命令/02-创建复制移动与删除.md)

## 7. 程序卡住或被暂停时

停止当前前台程序：

```text
Ctrl + C
```

误按 `Ctrl + Z` 时，程序通常只是暂停，没有退出。

查看当前 Shell 的任务：

```bash
jobs
```

恢复到前台：

```bash
fg
```

让暂停任务转入后台：

```bash
bg
```

后台任务不等于可以抵抗终端关闭或 SSH 断线。远程长任务应使用 tmux：

```bash
tmux new -s train
```

tmux 能保护会话免受 SSH 断开影响，但不能抵抗关机、重启、断电或程序崩溃。

## 8. 进入项目后先看 Git 状态

```bash
cd PROJECT_PATH
git status
git branch --show-current
```

工作完成后查看修改：

```bash
git status --short
git diff --stat
git diff
```

只暂存确认过的文件：

```bash
git add FILE_A FILE_B
git diff --cached
```

不要把下面这条命令当成无需检查的默认操作：

```bash
git add .
```

它可能把日志、缓存、大文件或敏感配置一起加入暂存区。

## 9. 一套每天都能使用的流程

```text
打开终端
→ hostname / whoami / pwd
→ cd 进入项目
→ ls -la
→ git status
→ 执行任务
→ 运行测试
→ git diff
→ 精确暂存
→ 人工提交
```

最小命令组合：

```bash
hostname
whoami
pwd
cd PROJECT_PATH
ls -la
git status
```

工作完成后：

```bash
git status --short
git diff --stat
git diff
```

## 10. 15 分钟安全练习

在单独的练习目录中运行：

```bash
mkdir -p ~/terminal-practice
cd ~/terminal-practice
pwd
touch notes.md
mkdir demo
cp notes.md notes-backup.md
mv notes-backup.md demo/
find . -maxdepth 2 -print
```

检查结果：

```bash
ls -la
ls -la demo
```

本练习不要求删除目录。暂时保留它，等理解路径和删除风险后再清理。

## 一页式速记

```text
确认机器：hostname
确认用户：whoami
确认目录：pwd
查看文件：ls -la
进入目录：cd PATH
返回上级：cd ..
回家目录：cd ~
看短文件：cat FILE
看长文件：less FILE
停止程序：Ctrl + C
看 Git 状态：git status
看修改：git diff
```

最重要的习惯：

> 先确认机器和路径，再执行会修改文件、环境或系统的命令。
