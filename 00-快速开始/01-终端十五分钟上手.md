# 01 终端十五分钟上手

> 适合第一次打开终端，或者隔了一段时间想快速找回基本操作的读者。  
> 这一页只完成一件事：在安全的练习目录中移动、创建文件、查看结果，并知道输错或程序卡住时怎样停下来。

打开 macOS 的 Terminal 后，你会看到一行提示符，末尾常见 `%`。提示符本身不用输入；只需在后面输入命令并按回车。Terminal 负责显示文字和接收键盘输入，命令通常由 zsh 解释。名词可以暂时放在一边，先通过一段连续练习熟悉操作节奏。

## 1. 确认机器、用户和当前位置

第一组命令用来确认操作发生在哪台机器、以哪个用户、从哪个目录开始：

```bash
hostname
whoami
pwd
```

输出会因电脑而异，例如：

```text
MacBook
student
/Users/student
```

`hostname` 显示当前机器名称，`whoami` 显示当前用户，`pwd` 显示当前工作目录。通过 SSH 登录 Ubuntu 后，窗口仍显示在 Mac 上，命令却已经在远程机器执行；删除文件、安装软件或启动训练前重新确认 `hostname` 和 `pwd`，可以避免把正确命令用在错误机器或目录。

使用 `ls` 查看普通文件，`ls -la` 还会显示隐藏文件和详细信息：

```bash
ls
ls -la
```

你可能看到 `.zshrc`、`.gitconfig` 等以 `.` 开头的配置文件。它们没有出现在 Finder 的普通视图中，不代表可以随意删除。

## 2. 在安全目录中完成一次文件操作

这次练习全部放在主目录下的 `terminal-practice/first-session`，不会接触真实项目。创建目录、进入目录并核对位置：

```bash
mkdir -p ~/terminal-practice/first-session
cd ~/terminal-practice/first-session
pwd
```

最后一条命令应输出类似：

```text
/Users/student/terminal-practice/first-session
```

若输出仍是其他目录，停在这里检查上一条 `cd` 是否报错。相对路径会从当前目录开始计算，站错位置后继续操作是新手最常见、也最容易扩大的错误之一。位置正确后执行 `ls -la`；新目录通常只显示 `.` 和 `..`，分别表示当前目录和上一级目录。

在练习目录中创建文件和子目录，复制文件、移动副本，再列出结果：

```bash
touch notes.md
mkdir examples
cp notes.md notes-backup.md
mv notes-backup.md examples/
find . -print
```

可能看到：

```text
.
./examples
./examples/notes-backup.md
./notes.md
```

`touch` 创建空文件，`mkdir` 创建目录，`cp` 复制文件，`mv` 把副本移动到 `examples`。最后的 `find` 从当前目录列出内容；练习目录很小，不需要依赖 GNU `find` 才支持的深度限制参数。现在无需记住所有选项，只要能根据输出确认文件出现在预期位置。

给 `notes.md` 写入一行文字并立即读取。`>` 会覆盖目标文件原有内容，所以这里只对刚创建的练习文件使用；真实配置或代码文件需要重新核对目标路径。

```bash
printf '第一次终端练习完成。\n' > notes.md
cat notes.md
```

应看到：

```text
第一次终端练习完成。
```

`cat` 适合查看很短的文件。内容较长时可以使用 `less FILE`，进入后按 `q` 退出，避免整份内容一次涌入屏幕。

## 3. 移动目录并修改尚未执行的命令

进入子目录观察位置和内容，然后返回上一级：

```bash
cd examples
pwd
ls -la
cd ..
pwd
```

`cd ~` 可以回到主目录，`cd -` 可以回到刚才所在的目录。目录名含空格时使用引号：

```bash
mkdir "My Project"
cd "My Project"
```

输入目录名前几个字符后按 Tab，可以让 zsh 补全名称。补全成功也说明当前目录中确实存在目标；没有补全时，用 `ls` 检查名称和当前位置，比反复猜路径更有效。

长命令输错时不必一直按退格。在普通 zsh 提示符中，先记住下面六个按键：

```text
Ctrl + A    移到行首
Ctrl + E    移到行尾
Ctrl + W    删除光标左侧一个单词
Ctrl + U    常见情况下清除当前输入
Ctrl + R    搜索以前输入过的命令
Ctrl + C    放弃当前输入，或中断正在运行的前台程序
```

快捷键可能被 Vi 模式、插件、tmux 或 AI CLI 界面重新定义。本机使用 zsh 时，可以查看 `Ctrl + U` 和 `Ctrl + W` 的实际绑定：

```bash
bindkey '^U'
bindkey '^W'
```

在不按回车的情况下输入下面这条长命令：

```text
python3 very/long/path/example.py --output result.txt
```

尝试用 `Ctrl + A`、`Ctrl + E` 和 `Ctrl + W` 移动或删除内容，最后按 `Ctrl + C` 放弃这一行。只要没有按回车，命令就没有执行；不确定内容时，可以直接取消后重新输入。

## 4. 路径出错或程序不停时怎样收手

尝试进入一个不存在的目录：

```bash
cd does-not-exist
```

终端会显示类似：

```text
cd: no such file or directory: does-not-exist
```

这条报错没有破坏内容，只说明目录没有切换成功。用 `pwd` 和 `ls -la` 确认自己仍在原目录，再检查拼写、大小写、空格和目标是否存在。连续猜测许多路径通常不如观察当前状态有效。

```bash
pwd
ls -la
```

运行一个会持续输出的命令，看到结果后按 `Ctrl + C`：

```bash
ping 127.0.0.1
```

程序应停止并返回提示符。`Ctrl + C` 通常中断当前前台程序，不会删除项目文件。误按 `Ctrl + Z` 时，程序往往只是暂停；用 `jobs` 查看任务，若仍在列表中，执行 `fg` 恢复到前台，再按 `Ctrl + C` 正常中断。

```bash
jobs
fg
```

按 `Ctrl + L` 或执行 `clear` 可以整理屏幕显示，不会删除历史命令、文件或已经执行过的操作。长时间训练需要 tmux、日志和 checkpoint，普通后台运行不能提供同样的保护。

## 5. 检查练习结果并形成启动习惯

回到练习目录，核对位置、文件结构和写入内容：

```bash
cd ~/terminal-practice/first-session
pwd
find . -print
cat notes.md
```

本练习不要求删除目录，保留它可以供后面练习 Git 和 AI CLI 使用。到这里，你已经完成最基本的一套循环：确认位置，执行小操作，根据输出判断结果，遇到错误时停下来观察，而不是继续叠加命令。

日常进入真实项目时，可以用下面几条命令建立现场：

```bash
hostname
pwd
ls -la
git status
```

`git status` 只在 Git 项目中有意义；普通目录显示“不是 Git 仓库”不代表终端故障。需要记住的核心问题是：这条命令会在哪台机器、哪个目录处理哪些对象？
