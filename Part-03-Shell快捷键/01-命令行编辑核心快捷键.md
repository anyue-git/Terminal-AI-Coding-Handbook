# 01 命令行编辑核心快捷键

在终端里输入长命令时，不需要一直按退格键。zsh、Bash 等 Shell 都带有行编辑器，可以快速移动、删除、恢复和搜索历史命令。

但先记住一个边界：

```text
普通 Shell 提示符
→ 快捷键由 zsh 或 Bash 处理

Claude Code、Codex、Grok、Vim、less、tmux
→ 快捷键可能由当前程序处理
```

所以同一个 `Ctrl + U`，在普通 zsh 和 AI CLI 输入框中不一定完全相同。

---

## 1. 先确认当前按键绑定

macOS 默认 Shell 通常是 zsh：

```bash
echo "$SHELL"
```

查看常见 zsh 绑定：

```bash
bindkey '^A'
bindkey '^E'
bindkey '^U'
bindkey '^K'
bindkey '^W'
bindkey '^Y'
```

插件、Vi 模式和终端配置都可能改变结果。本机 `bindkey` 输出比网上的速查表更可靠。

---

## 2. 最值得先记住的六个快捷键

### `Ctrl + A`：移动到行首

```text
Ctrl + A
```

适合修改命令开头，例如把 `python` 改成 `python3`。

### `Ctrl + E`：移动到行尾

```text
Ctrl + E
```

修改完开头后，可以快速回到行尾继续补参数。

### `Ctrl + W`：删除左侧一个单词

```text
Ctrl + W
```

适合删除错误参数、文件名或路径片段。不同配置对斜杠、连字符和标点的“单词边界”判断可能不同。

### `Ctrl + U`：清除当前输入

在 macOS 默认 zsh 的常见 Emacs 键位中：

```text
Ctrl + U
```

通常会清除整条当前输入，并把内容放入 zsh 的剪切缓冲区。

Bash/Readline 中常见行为可能是删除光标左侧到行首，所以准确行为取决于当前行编辑器和绑定。

### `Ctrl + K`：删除光标右侧到行尾

```text
Ctrl + K
```

适合保留命令开头，只重写后半部分。

### `Ctrl + C`：取消输入或中断前台程序

命令尚未执行时，它通常取消当前输入；程序已经运行时，它通常向前台程序发送中断信号。

```text
Ctrl + C
```

AI CLI 中可能表示停止生成、取消工具调用或退出当前选择界面。不要在权限弹窗不明时连续乱按回车。

---

## 3. 删除内容后怎样恢复

zsh 中的 `Ctrl + U`、`Ctrl + K` 和 `Ctrl + W` 常常属于 Kill 操作，而不是简单丢弃。

粘回最近删除的内容：

```text
Ctrl + Y
```

它使用的是 Shell 自己的剪切缓冲区，不是 macOS 的系统剪贴板。

例如：

```text
输入长命令
→ Ctrl + U 清除
→ 改变主意
→ Ctrl + Y 恢复
```

---

## 4. 按单词移动光标

许多 Mac 终端支持：

```text
Option + ←
Option + →
```

如果无效或出现奇怪字符，需要检查终端是否把 Option 设置为 Meta 或 Esc+。

兼容性更强的传统方式：

```text
Esc，然后按 B    向左一个单词
Esc，然后按 F    向右一个单词
```

删除前一个单词也常可使用：

```text
Option + Delete
```

不稳定时使用 `Ctrl + W`。

---

## 5. 搜索历史命令

按：

```text
Ctrl + R
```

然后输入关键词，例如：

```text
ssh
```

常见操作：

- 再按 `Ctrl + R`：查找更早的匹配；
- 按方向键：接受结果后继续编辑，具体取决于绑定；
- 按回车：直接执行；
- 按 `Ctrl + C`：取消搜索。

历史命令中可能包含旧地址、错误路径或危险参数。找到结果后先编辑检查，不要条件反射地回车。

方向键上、下也可以浏览历史，但 `Ctrl + R` 更适合找很久以前的命令。

---

## 6. 清理屏幕不等于删除内容

```text
Ctrl + L
```

通常相当于：

```bash
clear
```

它只整理显示区域，不会删除文件、历史命令或磁盘数据，也不会停止程序。

---

## 7. `Ctrl + D` 为什么需要谨慎

在默认 zsh 中，`Ctrl + D` 可能：

- 删除光标下的字符；
- 在行尾显示补全；
- 输入行为空时发送 EOF，并退出当前 Shell。

所以它不适合作为新手的普通 Delete 键。退出远程 SSH 或 Shell 时，优先明确输入：

```bash
exit
```

---

## 8. `Ctrl + Z` 只是暂停程序

```text
Ctrl + Z
```

通常把前台程序暂停，并放入当前 Shell 的任务列表。

查看：

```bash
jobs
```

恢复到前台：

```bash
fg
```

继续在后台：

```bash
bg
```

它不等于结束程序。普通中断优先使用 `Ctrl + C`。

---

## 9. AI CLI 中快捷键为什么不同

启动：

```bash
claude
codex
grok
```

之后，键盘输入通常先交给工具的 TUI，而不是 zsh。此时：

- `Ctrl + U` 可能由输入框重新定义；
- `Ctrl + C` 可能先取消生成，再退出程序；
- `Ctrl + D` 可能退出工具；
- Option 组合键可能受终端和 TUI 两层影响；
- tmux 前缀键还会增加第三层快捷键处理。

遇到差异时先查看当前工具帮助，不要为了修一个快捷键修改整个 Shell 配置。

---

## 10. 快捷键失效时的排查顺序

```text
先确认焦点在哪个程序
→ 检查是否处于 zsh Vi 模式
→ 使用 bindkey 查看真实绑定
→ 检查终端的 Option/Meta 设置
→ 检查 tmux 或插件是否拦截
→ 查看当前 AI CLI 的帮助
```

zsh 当前键位模式可以检查：

```bash
bindkey -L | head
```

临时切换到常见 Emacs 键位：

```bash
bindkey -e
```

不要在不了解现有配置时，把网上一整套快捷键配置直接追加到 `.zshrc`。

---

## 11. 最短记忆卡片

```text
Ctrl + A    行首
Ctrl + E    行尾
Ctrl + W    删除左侧一个单词
Ctrl + U    清除当前输入，具体行为看绑定
Ctrl + K    删除右侧到行尾
Ctrl + Y    粘回 Kill 内容
Ctrl + R    搜索历史
Ctrl + C    取消或中断
Ctrl + L    清屏
Ctrl + Z    暂停程序
```

先熟练 `A、E、W、U、C、R`，已经足以显著减少终端输入负担。
