# 01 命令行编辑核心快捷键

在终端输入长命令时，不需要一直按方向键和退格键。zsh 自带的 ZLE（Zsh Line Editor）可以快速移动光标、删除一段内容、恢复刚删掉的文字和搜索历史。先熟悉少数高频按键，就能在命令输错时停下来修改，而不是勉强执行。

不过，快捷键由当前接收键盘输入的程序决定。普通 zsh 提示符通常由 ZLE 处理；进入 Claude Code、Codex CLI、Grok CLI、Vim、`less` 或 tmux 后，按键可能被重新定义。同一个 `Ctrl + U` 在不同界面中不一定有相同行为。

## 1. 先做一条不会执行的练习

在普通 zsh 提示符中输入下面这一行，但不要按回车：

```text
python3 scripts/train_model.py --config configs/experiment.yaml --output runs/demo
```

接下来的移动和删除都作用于尚未执行的文字。任何时候不确定，都可以按 `Ctrl + C` 放弃当前输入并返回新提示符。

先确认当前 Shell 和按键绑定：

```bash
echo "$SHELL"
ps -p $$ -o comm=
bindkey '^A'
bindkey '^E'
bindkey '^U'
bindkey '^K'
bindkey '^W'
bindkey '^Y'
```

插件、Vi 模式和个人配置可能改变结果，本机 `bindkey` 输出比通用速查表更可靠。

## 2. 移动光标：行首、行尾和单词之间

`Ctrl + A` 移到行首，`Ctrl + E` 回到行尾。可以在刚才的长命令中先按 `Ctrl + A`，修改开头的 `python3`，再按 `Ctrl + E` 继续补参数。完成后按 `Ctrl + C` 取消，不执行练习命令。

很多 Mac 终端还支持：

```text
Option + ←    向左移动一个单词
Option + →    向右移动一个单词
```

若没有效果或输入奇怪字符，需要检查 Terminal、iTerm2 等是否把 Option 配置为 Meta/Esc+。兼容性较强的传统按法是先按 `Esc`，再按 `B` 向左或 `F` 向右。按键差异来自终端应用和 ZLE 配置，不是命令内容发生了变化。

## 3. 删除和恢复：`Ctrl + W/U/K/Y`

重新输入：

```text
python3 app.py --output wrong-directory
```

光标位于行尾时，`Ctrl + W` 通常删除左侧一个“单词”，然后可以输入正确路径。斜杠、连字符和标点是否算边界取决于配置，因此先观察一次变化，不要连续按很多次后才检查。

在 macOS 常见的 zsh Emacs 键位中，`Ctrl + U` 常清理整条当前输入；Bash/Readline 的常见行为可能是删除光标左侧到行首，所以应以 `bindkey '^U'` 为准。`Ctrl + K` 删除光标右侧到行尾，适合保留命令前半部分并重写后续参数。

这些按键通常属于 Kill 操作，被删除的文字进入 Shell 自己的缓冲区。`Ctrl + Y` 可以恢复最近一次 Kill 内容：

```text
输入长命令
→ Ctrl + U 清除
→ Ctrl + Y 恢复
→ Ctrl + C 取消
```

这个缓冲区不是 macOS 系统剪贴板，`Command + V` 和 `Ctrl + Y` 读取不同来源。以上操作只修改尚未执行的输入，不能撤销已经运行的程序或文件变化。

## 4. `Ctrl + R` 搜索历史，但执行前仍要复核

按 `Ctrl + R` 后输入关键词，例如 `ssh`，zsh 会搜索以前输入过的匹配命令；再次按下通常继续寻找更早结果。找到后进入编辑状态，检查服务器地址、路径、分支、输出目录和危险参数，再决定是否回车。`Ctrl + C` 可以取消搜索。

方向键上、下适合浏览最近几条记录，`Ctrl + R` 更适合较早命令。历史记录来自过去的现场，旧服务器、目录和任务可能已经变化，看到熟悉命令不能条件反射地执行。包含 Token、Cookie 或密码的历史还涉及凭证泄露，不能只靠清屏处理。

## 5. `Ctrl + C/Z/L/D` 解决的是不同问题

命令尚未执行时，`Ctrl + C` 通常取消当前输入；程序运行后，它通常向前台进程发送中断信号。可以用 `ping 127.0.0.1` 练习，看到持续输出后按 `Ctrl + C` 返回提示符。部分程序会先清理状态，AI CLI 也可能第一次只取消当前生成或工具调用，应观察界面提示。

`Ctrl + Z` 是暂停，不是结束。运行程序时按下后，用：

```bash
jobs
fg
```

查看并恢复到前台；`bg` 可以让暂停任务在后台继续。普通后台任务不能保证抵抗终端关闭、SSH 断线、关机或程序崩溃，远程长任务仍需 tmux、日志和 checkpoint。

`Ctrl + L` 通常等同于 `clear`，只清理显示区域，不会删除文件、Shell 历史或已执行操作，也不会停止程序。若误把 Token 输入命令行，清屏不能消除风险。

`Ctrl + D` 与输入状态有关，可能删除光标下字符、触发补全，或在空输入行发送 EOF 并退出当前 Shell。新手不要把它当普通 Delete；退出 SSH 或 Shell 时优先明确输入 `exit`。

## 6. 进入 AI CLI 或 tmux 后，按键会经过更多层

在普通 Shell 中启动 `claude` 或 `codex` 后，键盘先交给客户端 TUI，而不是 zsh。此时 `Ctrl + U` 可能由输入框定义，`Ctrl + C` 先取消生成，`Ctrl + D` 可能退出工具；tmux 还会增加前缀键这一层。遇到差异时，先判断焦点在哪个程序，再查看程序内帮助，不要为了修一个 TUI 按键直接重写 `.zshrc` 或终端配置。

回到普通 zsh 提示符后，可以按层检查：

```bash
ps -p $$ -o comm=
bindkey '^U'
bindkey '^W'
bindkey -L | head
```

调查顺序是：当前焦点在哪个程序，当前是否真是 zsh，是否启用 Vi 键位，`bindkey` 的真实结果，终端怎样处理 Option/Meta，tmux 或插件是否拦截，当前 AI CLI 是否重新定义按键。`bindkey -e` 可以在当前会话临时切换到常见 Emacs 键位，确认来源后再决定是否永久修改。

## 7. 先熟练这一小组就够了

```text
Ctrl + A    移到行首
Ctrl + E    移到行尾
Ctrl + W    删除左侧一个单词
Ctrl + U    清理当前输入，实际行为看绑定
Ctrl + K    删除右侧到行尾
Ctrl + Y    恢复最近 Kill 的内容
Ctrl + R    搜索历史
Ctrl + C    取消输入或中断前台程序
Ctrl + L    清屏
Ctrl + Z    暂停程序
```

先熟练 `A、E、W、U、R、C`，已经能处理大多数日常输入问题。快捷键的目的不是增加记忆负担，而是让你清楚当前文字尚未执行、可以修改或取消。
