# 01 命令行编辑核心快捷键

在终端里输入长命令时，不需要一直按方向键和退格键。zsh 自带的行编辑器可以移动光标、删除一段内容、恢复刚删掉的文字和搜索历史命令。先熟悉少数高频按键，输入体验会改善很多。

不过，快捷键由当前接收键盘输入的程序决定。在普通 zsh 提示符中，按键通常由 ZLE（Zsh Line Editor）处理；进入 Claude Code、Codex CLI、Grok CLI、Vim、`less` 或 tmux 后，按键可能被这些程序重新定义。同一个 `Ctrl + U` 在不同界面中不一定有相同行为。

## 1. 先做一个不会执行的练习

在普通 zsh 提示符中输入下面这一行，但先不要按回车：

```text
python3 scripts/train_model.py --config configs/experiment.yaml --output runs/demo
```

接下来的移动和删除练习都在这行尚未执行的文字上完成。任何时候不确定，都可以按 `Ctrl + C` 放弃当前输入并回到新的提示符。

确认当前 Shell：

```bash
echo "$SHELL"
ps -p $$ -o comm=
```

使用 zsh 时，可以查看实际绑定：

```bash
bindkey '^A'
bindkey '^E'
bindkey '^U'
bindkey '^K'
bindkey '^W'
bindkey '^Y'
```

插件、Vi 模式和个人配置可能改变结果，本机 `bindkey` 输出比通用速查表更可靠。

## 2. `Ctrl + A` 和 `Ctrl + E`：快速到行首、行尾

按：

```text
Ctrl + A
```

光标会移动到行首。假设你发现命令应该使用另一套 Python，可以直接修改开头，而不必逐字符左移。

按：

```text
Ctrl + E
```

光标回到行尾，适合继续补充参数。

可以这样练习：在长命令中按 `Ctrl + A`，把 `python3` 改成 `python`，再按 `Ctrl + E` 回到末尾。完成后按 `Ctrl + C` 取消，不执行这条练习命令。

## 3. `Ctrl + W`：删除光标左侧一个单词

重新输入一条较长命令：

```text
python3 app.py --output wrong-directory
```

将光标放在行尾，按：

```text
Ctrl + W
```

通常会删除左侧的 `wrong-directory`。再输入正确路径即可。

zsh 对“一个单词”的判断受配置影响。斜杠、连字符和标点可能被视为边界，因此删除路径时一次 `Ctrl + W` 不一定正好删除你预想的部分。先观察变化，不要连续按很多次后才检查。

## 4. `Ctrl + U` 和 `Ctrl + K`：删除一大段输入

在 macOS 常见的 zsh Emacs 键位中，`Ctrl + U` 通常清除整条当前输入：

```text
Ctrl + U
```

Bash/Readline 的常见行为可能是删除光标左侧到行首，因此不能把它机械理解成所有环境都“整行删除”。使用 `bindkey '^U'` 可以确认当前 zsh 行为。

`Ctrl + K` 会删除光标右侧到行尾：

```text
Ctrl + K
```

例如命令前半部分正确，后面参数全部要重写，可以把光标移动到错误部分之前，再按 `Ctrl + K`。

这两个按键适合清理尚未执行的输入。命令已经运行后，它们不会撤销程序造成的文件修改。

## 5. `Ctrl + Y`：恢复刚才删除的内容

zsh 中的 `Ctrl + U`、`Ctrl + K` 和 `Ctrl + W` 常属于 Kill 操作，删除的文字会进入 Shell 自己的缓冲区。按：

```text
Ctrl + Y
```

可以把最近 Kill 的内容粘回来。

练习过程：

```text
输入一条长命令
→ Ctrl + U 清除
→ Ctrl + Y 恢复
→ Ctrl + C 取消
```

这个缓冲区不是 macOS 系统剪贴板。`Command + V` 与 `Ctrl + Y` 读取的是不同来源。

## 6. 按单词移动光标

许多 Mac 终端支持：

```text
Option + ←    向左移动一个单词
Option + →    向右移动一个单词
```

如果没有效果，或者终端输入了奇怪字符，需要检查 Terminal、iTerm2 或其他终端是否把 Option 设置成 Meta/Esc+。

兼容性较强的传统按法是：

```text
先按 Esc，再按 B    向左一个单词
先按 Esc，再按 F    向右一个单词
```

删除左侧单词还可能支持 `Option + Delete`，但不同终端配置差异较大。`Ctrl + W` 通常更容易验证。

## 7. `Ctrl + R`：搜索历史命令

按：

```text
Ctrl + R
```

然后输入关键词，例如：

```text
ssh
```

zsh 会搜索以前输入过的匹配命令。再按一次 `Ctrl + R`，通常会继续寻找更早的结果。找到后可以用方向键或其他移动键进入编辑状态，检查地址、路径和参数，再决定是否回车执行。

按 `Ctrl + C` 可以取消搜索。不要看到熟悉的历史命令就条件反射地回车；旧命令可能包含已经变化的服务器地址、分支名、输出目录或危险参数。

方向键上、下适合浏览最近几条记录，`Ctrl + R` 更适合寻找较早命令。

## 8. `Ctrl + C`：取消当前输入或中断前台程序

命令尚未执行时，`Ctrl + C` 通常会放弃当前输入并显示新的提示符。

程序已经运行时，它通常向前台程序发送中断信号。可以练习：

```bash
ping 127.0.0.1
```

看到持续输出后按 `Ctrl + C`，程序应停止并返回 Shell。

并非每个程序都会立即退出。有些程序会捕获中断信号，先保存状态或等待清理。不要因为第一次没有马上响应就连续发送各种信号；先观察程序提示和文档。

在 AI CLI 中，`Ctrl + C` 可能先取消当前生成或工具调用，再次按下才退出程序。具体行为以当前工具界面和帮助为准。

## 9. `Ctrl + Z` 只是暂停，不是结束

程序运行时按：

```text
Ctrl + Z
```

通常会把前台程序暂停，并放入当前 Shell 的任务列表。查看：

```bash
jobs
```

可能看到：

```text
[1]  + suspended  ping 127.0.0.1
```

恢复到前台：

```bash
fg
```

让它在后台继续：

```bash
bg
```

后台运行不代表任务能够抵抗终端关闭、SSH 断线、关机或程序崩溃。远程长任务应使用 tmux、日志和 checkpoint。

## 10. `Ctrl + L`：清理显示区域

按：

```text
Ctrl + L
```

通常相当于执行：

```bash
clear
```

它只是把当前提示符移动到较干净的屏幕区域，不会删除文件、Shell 历史或已经执行的命令，也不会停止正在运行的程序。

如果之前误把 Token 输入命令行，清屏不能消除泄露风险。凭证可能仍存在于历史文件、终端滚动区、日志或截图中。

## 11. `Ctrl + D` 为什么不适合当普通删除键

在 zsh 中，`Ctrl + D` 的行为与光标和输入状态有关。它可能删除光标下的字符、显示补全，或者在输入行为空时发送 EOF 并退出当前 Shell。

因此，新手不要把它当作通用 Delete。退出 SSH 或 Shell 时，优先明确输入：

```bash
exit
```

这样操作意图更清楚，也能减少误退出当前会话。

## 12. 为什么进入 AI CLI 后快捷键会变化

在普通 Shell 中运行：

```bash
claude
```

或：

```bash
codex
```

启动以后，键盘输入先交给 AI CLI 的 TUI，而不是 zsh。此时可能出现：

- `Ctrl + U` 由输入框重新定义；
- `Ctrl + C` 先取消生成或命令执行；
- `Ctrl + D` 用于退出工具；
- Option 组合键同时受到终端和 TUI 影响；
- tmux 前缀键增加第三层按键处理。

遇到差异时，先判断焦点在哪个程序，再查看工具内帮助。不要为了修复 AI CLI 的一个按键，直接修改整个 `.zshrc` 或终端键盘设置。

## 13. 快捷键失效时按层排查

先退出全屏程序或 AI CLI，回到普通 zsh 提示符，再检查：

```bash
ps -p $$ -o comm=
bindkey '^U'
bindkey '^W'
bindkey -L | head
```

排查顺序可以是：

```text
当前焦点在哪个程序
→ 当前是否真的是 zsh
→ 是否启用了 Vi 键位
→ bindkey 的真实绑定是什么
→ 终端如何处理 Option/Meta
→ tmux 或插件是否拦截
→ 当前 AI CLI 是否重新定义按键
```

临时切换到常见 Emacs 键位：

```bash
bindkey -e
```

只在当前会话验证。确认问题来源后，再决定是否修改永久配置。

## 14. 先熟练这一组就够了

```text
Ctrl + A    行首
Ctrl + E    行尾
Ctrl + W    删除左侧一个单词
Ctrl + U    清理当前输入，实际行为看绑定
Ctrl + K    删除右侧到行尾
Ctrl + Y    恢复最近 Kill 的内容
Ctrl + R    搜索历史
Ctrl + C    取消输入或中断前台程序
Ctrl + L    清屏
Ctrl + Z    暂停程序
```

先熟练 `A、E、W、U、R、C`，已经可以处理大多数日常输入问题。快捷键的目的不是增加记忆负担，而是让你在长命令输错时敢于停下来修改，而不是抱着“差不多能运行”的心态直接回车。
