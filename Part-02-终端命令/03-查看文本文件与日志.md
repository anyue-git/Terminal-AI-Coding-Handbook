# 03 查看文本文件与日志

不同工具适合不同规模的文件：

```text
cat      小文件完整输出
less     长文件分页浏览
head     查看开头
tail     查看结尾
tail -f  持续观察新增日志
wc       统计规模
```

---

## 1. 先判断文件类型和大小

```bash
file PATH_TO_FILE
ls -lh PATH_TO_FILE
wc -l PATH_TO_FILE
```

大型日志、模型权重、压缩包和二进制文件不要直接 `cat`。

---

## 2. `cat`：查看短文件

```bash
cat README.md
```

适合简短配置、Markdown 和小型日志。

拼接文件：

```bash
cat part1.txt part2.txt > combined.txt
```

注意：`>` 会覆盖已存在的目标文件。

---

## 3. `less`：分页浏览长内容

```bash
less app.log
```

常用按键：

```text
Space   下一页
b       上一页
/word   搜索
n       下一个匹配
G       文件末尾
g       文件开头
q       退出
```

进入一个不能输入 Shell 命令的界面时，可能只是分页器。先尝试按 `q`。

---

## 4. `head` 和 `tail`

查看前 30 行：

```bash
head -n 30 data.csv
```

查看最后 100 行：

```bash
tail -n 100 training.log
```

实时追踪：

```bash
tail -f training.log
```

停止追踪：

```text
Ctrl + C
```

日志轮转场景中，macOS BSD 工具和 GNU/Linux 参数可能不同，应查看本机 `man tail`。

---

## 5. `tee`：边看边保存

```bash
python train.py 2>&1 | tee training.log
```

追加：

```bash
python train.py 2>&1 | tee -a training.log
```

脚本中使用管道时，为了保留训练命令的失败状态，可启用：

```bash
set -o pipefail
```

---

## 6. 统计规模

```bash
wc -l app.log
wc -w README.md
wc -c data.json
```

这些命令适合在交给 AI 或进一步处理前判断文件规模。

---

## 7. 查看 JSON、CSV 和二进制

JSON：

```bash
jq . config.json
```

CSV：

```bash
head -n 5 data.csv
```

二进制：

```bash
file model.bin
ls -lh model.bin
```

如果误把二进制输出到终端导致显示异常，可以尝试：

```bash
reset
```

---

## 8. 日志可能包含敏感信息

交给云端 AI 前先检查：

```bash
rg -n 'API_KEY|TOKEN|PASSWORD|Authorization|Cookie' training.log
```

还应留意：

- 用户名和本机路径；
- 服务器地址；
- 请求头；
- 内部代码；
- 数据集信息。

脱敏后再提供给模型。

---

## 9. 常见故障

文件不存在：

```bash
pwd
ls -la
```

权限不足：

```bash
ls -l PATH_TO_FILE
```

不要因为读不到就立即加 `sudo`。先确认文件所有者和访问目的。

---

## 10. 最短选择规则

```text
小文件 → cat
长文件 → less
开头 → head
结尾 → tail
实时日志 → tail -f
边看边保存 → tee
```
