# 02 创建、复制、移动与删除

终端中的文件操作依赖路径，而不是屏幕上的图标。执行前至少确认：

```bash
pwd
ls -la
```

建议先在练习目录中操作：

```bash
mkdir -p ~/terminal-practice/file-operations
cd ~/terminal-practice/file-operations
```

---

## 1. 创建目录和文件

创建目录：

```bash
mkdir notes
mkdir -p project/src/components
```

路径有空格：

```bash
mkdir "My Project"
```

创建空文件：

```bash
touch README.md
```

`touch` 遇到已存在文件时通常只更新时间戳，不会清空内容。

---

## 2. 复制文件和目录

复制文件：

```bash
cp notes.txt notes-backup.txt
```

复制到目录：

```bash
cp notes.txt backups/
```

目标已存在时可能被覆盖。可以使用：

```bash
cp -i new-config.yaml config.yaml
```

复制目录：

```bash
cp -R project project-backup
```

复制大型目录前先看大小：

```bash
du -sh project
```

源码项目应使用 Git 记录变化，不要长期依赖 `final-final2` 式目录副本。

---

## 3. 移动和重命名

重命名：

```bash
mv old-name.txt new-name.txt
```

移动：

```bash
mv report.md notes/
```

目标路径存在同名文件时可能覆盖。需要确认时：

```bash
mv -i draft.md final.md
```

不确定目标是文件还是目录：

```bash
ls -ld TARGET
file TARGET
```

---

## 4. 删除文件

```bash
rm notes.txt
```

`rm` 通常不会把文件送进 macOS 废纸篓，也没有通用撤销按钮。

新手可以使用：

```bash
rm -i notes.txt
```

批量删除前先预览：

```bash
ls -l *.log
```

确认后再处理：

```bash
rm -i *.log
```

通配符通常由 Shell 先展开，所以一个模式可能匹配很多文件。

---

## 5. 删除目录

删除空目录：

```bash
rmdir empty-folder
```

递归删除非空目录：

```bash
rm -R folder
```

下面的命令风险更高：

```bash
rm -rf folder
```

`-R` 递归，`-f` 减少确认和报错。执行递归删除前至少检查：

```bash
hostname
pwd
ls -la folder
du -sh folder
```

不确定时不要使用 `-f`。可以先移动到待删除目录：

```bash
mkdir -p ~/Trash-Staging
mv old-results ~/Trash-Staging/
```

观察一段时间后再清理。

---

## 6. 名称以 `-` 开头的文件

假设文件名为：

```text
-important.txt
```

删除时使用：

```bash
rm -- -important.txt
```

或：

```bash
rm ./-important.txt
```

`--` 表示后面的内容不再作为选项解析。

---

## 7. 变量中的路径

使用双引号：

```bash
cp "$SOURCE_FILE" "$BACKUP_DIR/"
```

执行前打印：

```bash
printf 'SOURCE=%s\nDEST=%s\n' "$SOURCE_FILE" "$BACKUP_DIR"
```

变量为空或路径意外时立即停止。

---

## 8. Git 仓库中的恢复边界

操作前：

```bash
git status
```

操作后：

```bash
git status --short
git diff --stat
git diff
```

Git 跟踪的文件被误删且尚未提交时，可以先查看：

```bash
git diff -- PATH_TO_FILE
```

确认要丢弃未提交修改后再恢复：

```bash
git restore PATH_TO_FILE
```

未跟踪文件被 `rm` 删除后，Git 通常无法恢复。

---

## 9. 给 AI CLI 的约束

```text
只允许修改当前项目中明确列出的文件。
删除、覆盖、移动目录或使用通配符前，先列出目标和影响范围。
不要使用 rm -rf，不要删除未跟踪文件，不要操作项目外路径。
完成后列出所有变更文件并显示 git diff。
```
