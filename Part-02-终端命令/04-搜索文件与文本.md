# 04 搜索文件与文本

终端搜索分成两类：

```text
找文件
→ 文件在哪里

找内容
→ 哪些文件中出现了某段文字
```

常用工具：

- `find`：按名称、类型、时间和路径找文件；
- `grep`：在指定文本中搜索；
- `rg`：在代码仓库中快速搜索。

---

## 1. `find`：按文件属性搜索

找 Markdown 文件：

```bash
find . -type f -name '*.md'
```

忽略大小写：

```bash
find . -iname '*readme*'
```

只找目录：

```bash
find . -type d -name 'node_modules'
```

限制深度：

```bash
find . -maxdepth 2 -type f
```

macOS BSD `find` 和 GNU/Linux `find` 的部分参数不同。遇到不确定选项时查看：

```bash
man find
```

---

## 2. 搜索结果先当作只读清单

不要直接把搜索连接到删除：

```bash
find . -name '*.log' -delete
```

先打印：

```bash
find . -type f -name '*.log' -print
```

确认目录、数量和文件名后，再决定怎样处理。

自动搜索和自动修改结合时，影响范围会被迅速放大。

---

## 3. `grep`：搜索指定文本

```bash
grep 'ERROR' app.log
```

显示行号：

```bash
grep -n 'ERROR' app.log
```

忽略大小写：

```bash
grep -ni 'error' app.log
```

递归搜索：

```bash
grep -Rni 'API_KEY' .
```

显示前后两行：

```bash
grep -n -C 2 'ERROR' app.log
```

正则表达式中的 `.`、`*`、`[` 等符号具有特殊含义。只想匹配普通文本时，注意引号和转义。

---

## 4. `rg`：更适合代码仓库

搜索：

```bash
rg 'TODO'
```

指定目录：

```bash
rg 'login' src/
```

显示行号和上下文：

```bash
rg -n -C 2 'ERROR'
```

列出文件：

```bash
rg --files
```

按文件类型：

```bash
rg -t py 'import torch'
```

`rg` 通常尊重 `.gitignore`，所以速度快，也会跳过许多构建产物和缓存。但这意味着它不一定搜索所有文件。

查看隐藏文件：

```bash
rg --hidden 'TOKEN'
```

隐藏文件可能包含凭据，搜索结果不要直接发给外部服务。

---

## 5. 三个工具怎样选

```text
名称、类型、时间、目录
→ find

一个或少量指定文件
→ grep

代码仓库全文搜索
→ rg
```

例如：

```bash
find . -type f -name '*.py'
rg -n 'torch\.cuda'
```

---

## 6. 文件名有空格时

不要使用：

```bash
for file in $(find . -name '*.txt'); do
  echo "$file"
done
```

命令替换会按空白拆分文件名。

需要把 `find` 结果传给其他命令时，可以使用空字符分隔：

```bash
find . -name '*.txt' -print0 | xargs -0 grep -n 'TODO'
```

不过单纯搜索文本时，直接使用 `rg` 或 `grep -R` 通常更清楚。

---

## 7. 搜索敏感信息

提交前可以进行基础检查：

```bash
rg -n --hidden 'API_KEY|SECRET|TOKEN|PASSWORD|Authorization|Cookie'
```

这只能找到明显文本，不能代替：

- `.gitignore`；
- Secret Scanner；
- 凭据轮换；
- Git 历史检查；
- 人工审查。

发现真实凭据时，不要只删除文件。已经泄露或提交的凭据应立即撤销并更换。

---

## 8. 给 AI CLI 的搜索任务

```text
当前阶段只读。
请使用 rg、find 或项目索引定位相关实现。
列出文件路径、关键行号和判断依据。
不要读取 .env、SSH 私钥、云凭据或项目外目录。
不要修改文件。
```

搜索结果是定位线索，不是修改授权。
